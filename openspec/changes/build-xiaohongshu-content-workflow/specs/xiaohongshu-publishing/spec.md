## ADDED Requirements

### Requirement: 安全管理小红书账号授权

系统必须（SHALL）使用账号别名、授权类型、密钥引用、健康状态和最后检查时间表示每个小红书账号，并且不得（MUST NOT）在业务记录或客户端 API 中保存或返回原始 Cookie 或凭据。

#### Scenario: 账号授权状态正常

- **WHEN** 已授权的运营人员请求检查账号，并且适配器确认会话有效
- **THEN** 系统记录账号健康状态和检查时间，且不暴露任何密钥材料

#### Scenario: 需要交互式验证

- **WHEN** 适配器报告授权过期、扫码登录、验证码、短信验证或异常登录确认
- **THEN** 账号及受影响的发布任务进入人工处理状态，并停止自动重试

### Requirement: 应用版本化的小红书策略

系统必须（SHALL）依据版本化的小红书平台策略校验标题、正文、标签、媒体数量、媒体格式、必需封面、AIGC 标识、审核模式和内容类型，而不是使用写死在提示词中的限制。

#### Scenario: 内容违反有效策略

- **WHEN** 草稿或排队中的内容超过硬性限制，或缺少必需的媒体或标识
- **THEN** 系统在调用外部发布前返回校验失败结果，其中包含策略版本和可操作的违规信息

#### Scenario: 批准后平台策略发生变化

- **WHEN** 在外部发布调用前已有更新的平台策略生效
- **THEN** Worker 使用当前有效策略重新校验，并将不合规任务退回修改，而不是发布无效内容

### Requirement: 隔离 Publisher Adapter 的执行

系统必须（SHALL）通过独立 Publisher Worker 调用实现 `checkAuth`、`validate`、`preview`、`publish` 和 `queryStatus` 的小红书适配器，并且 Publisher 故障不得（MUST NOT）导致 API、研究 Worker 或内容 Worker 崩溃。

#### Scenario: MCP 辅助进程不可用

- **WHEN** Publisher Worker 无法连接固定版本的小红书 MCP sidecar
- **THEN** 发布任务记录已分类的集成错误，按照重试策略处理，系统其他能力保持可用

#### Scenario: 适配器契约冒烟测试失败

- **WHEN** 部署校验发现 sidecar 不再满足适配器契约
- **THEN** 系统保持发布器禁用，并且不把排队任务发送到平台

### Requirement: 按账号串行处理并限制发布频率

系统必须（SHALL）通过账号级队列处理小红书图文发布，并应用可配置的并发数、令牌桶限制和有界调度抖动。

#### Scenario: 多篇内容同时发送到同一账号

- **WHEN** 同一账号的多个发布任务同时就绪
- **THEN** 系统遵守该账号的并发和滚动窗口策略，而不是突发发布

#### Scenario: 不同账号均有可用容量

- **WHEN** 任务属于不同的健康账号，并且每个账号都处于策略限额内
- **THEN** 这些任务可以独立推进，而不共享一个全局锁

### Requirement: 防止可避免的重复发布

系统必须（SHALL）根据工作空间、平台账号、内容制品版本和发布时段生成稳定的发布幂等键，并在解析或创建平台副作用时持有数据库锁。

#### Scenario: 发布回执已经存在

- **WHEN** Worker 收到一个已经存在发布回执的任务
- **THEN** Worker 查询或返回现有平台结果，并且不再次调用发布操作

#### Scenario: 两个 Worker 收到相同任务

- **WHEN** 重复的队列投递被并发处理
- **THEN** 只有持有发布锁的 Worker 可以评估并创建外部副作用

#### Scenario: 发布响应丢失

- **WHEN** 外部调用可能已经成功，但没有持久化明确响应
- **THEN** 任务进入未知结果或人工处理状态，并且系统必须先执行平台侧核验，再允许任何重试

### Requirement: 保存并核验发布回执

系统必须（SHALL）在把发布任务标记为成功前，保存平台内容标识、可用的平台 URL、请求哈希、已脱敏响应、发布时间、策略版本和核验状态。

#### Scenario: 平台返回成功结果

- **WHEN** 适配器返回平台内容标识或等价回执
- **THEN** 系统保存回执，执行或调度状态核验，然后才把任务转换为成功状态

#### Scenario: 已发布内容后续核验失败

- **WHEN** `queryStatus` 报告内容不存在、被拒绝或不可用
- **THEN** 系统更新核验状态，记录结果，展示人工处理项，并且不得盲目重新发布

### Requirement: 重试前对失败进行分类

系统必须（SHALL）只对已声明的瞬时错误执行有界指数退避和抖动重试，并将授权、验证、策略、内容、页面选择器和未知结果错误转交人工处理。

#### Scenario: 副作用发生前出现瞬时超时

- **WHEN** 适配器把超时分类为可安全重试，并确认没有发生外部副作用
- **THEN** 系统调度一次有界重试，并增加尝试次数

#### Scenario: 页面选择器或页面契约发生变化

- **WHEN** 适配器报告 DOM 选择器或页面契约错误
- **THEN** 系统打开适配器熔断器，停止发送后续任务，并通知运营人员

### Requirement: 审计每一次外部发布操作

系统必须（SHALL）记录每个发布任务的批准、入队、尝试、重试、核验或人工解决主体和动作，同时不得记录密钥。

#### Scenario: 运营人员手工重试任务

- **WHEN** 运营人员重试一个符合重试条件的失败发布任务
- **THEN** 系统记录操作主体、原因、之前的错误、所选内容版本和新产生的尝试
