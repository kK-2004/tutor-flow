# 首期验收清单

## 原型覆盖

管理台路由覆盖 `docs/原型.html` 的概览、工作流、任务详情、草稿箱、草稿编辑、研究资料、发布管理和系统设置；创建任务模态框只出现小红书账号和小红书平台。服务端 API、SSE 和数据库是业务状态来源，浏览器本地只保存主题偏好。

## 影子验证

使用测试账号执行以下顺序，并在审计事件中记录操作者、策略版本和适配器版本：

1. 禁用发布副作用，仅执行调度触发、检索、选向、生成、草稿和规则校验。
2. 断开 MCP sidecar，确认 API、研究 Worker 和草稿箱仍可用，发布任务进入已分类人工状态。
3. 恢复 sidecar，执行授权、预览、契约校验和平台状态查询。
4. 开启仅人工批准发布，批准一篇测试草稿，核对回执优先落库、核验和 SSE 重放。
5. 注入响应丢失、授权失效、策略漂移和选择器错误，确认不会盲目重发。

真实测试账号、sidecar commit 和镜像摘要由部署环境提供；未提供这些外部凭据时不得声称已经完成生产发布验证。
