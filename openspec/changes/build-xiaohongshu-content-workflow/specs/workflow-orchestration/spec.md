## ADDED Requirements

### Requirement: 创建小红书内容运行任务

系统必须（SHALL）允许已认证的运营人员使用非空主题、方向模式（`auto` 或 `manual`）、发布模式（`review` 或 `auto`）、小红书账号以及唯一目标平台 `xiaohongshu` 创建运行任务。

#### Scenario: 运营人员创建有效任务

- **WHEN** 已认证的运营人员提交有效的运行参数
- **THEN** 系统创建状态为 `QUEUED` 的持久化运行任务，记录人工触发审计事件，并调度第一个步骤

#### Scenario: 请求不支持的平台

- **WHEN** 创建请求包含 `xiaohongshu` 之外的任何目标平台
- **THEN** 系统返回校验错误，并且不创建运行任务

### Requirement: 接受幂等的外部定时触发

系统必须（SHALL）向已授权的外部调度器提供运行任务创建接口，并要求调度器请求携带 Bearer 凭据和 `Idempotency-Key`。

#### Scenario: 调度器重试相同请求

- **WHEN** 同一调度器身份使用相同幂等键和等价载荷重复请求
- **THEN** 系统返回最初创建的运行任务，并且不重复入队

#### Scenario: 调度器使用相同键提交不同输入

- **WHEN** 同一调度器身份使用已存在的幂等键提交不同载荷
- **THEN** 系统返回冲突响应，并保留原运行任务

#### Scenario: 调度器凭据无效

- **WHEN** 外部触发请求缺少凭据或凭据无效
- **THEN** 系统拒绝请求，且不泄露运行数据或创建任务

### Requirement: 执行可持久恢复的工作流状态机

系统必须（SHALL）持久化每一次工作流状态转换和步骤尝试，并且必须（MUST）能够在 API 或 Worker 重启后继续未终止的运行任务，且不重复已完成的外部副作用。

#### Scenario: 工作进程在步骤完成后重启

- **WHEN** Worker 在提交步骤结果后停止并于稍后重启
- **THEN** 恢复流程从下一个未完成步骤继续执行，并使用已持久化的检查点

#### Scenario: 收到过期的队列投递

- **WHEN** Worker 收到一个已标记完成步骤的任务
- **THEN** Worker 确认该任务，但不重新执行该步骤

### Requirement: 支持人工和自动选择内容方向

系统必须（SHALL）在生成候选方向后暂停人工选向任务，并且只有至少一个方向满足已配置的质量和风险门槛时，才允许自动选向任务继续。

#### Scenario: 人工任务已有候选方向

- **WHEN** 人工选向任务完成方向生成
- **THEN** 任务进入 `WAITING_DIRECTION`，提供结构化候选方向，并且在运营人员完成选择前不调度内容生成

#### Scenario: 自动任务存在合格方向

- **WHEN** 自动选向任务存在一个或多个满足全部门槛的方向
- **THEN** 系统选择总分最高的合格方向，记录决策输入，并继续内容生成

#### Scenario: 没有合格的自动方向

- **WHEN** 没有方向同时满足来源覆盖率、主要来源数量、合规风险和分数门槛
- **THEN** 系统进入 `NEEDS_HUMAN`，不得为了完成任务而生成或发布内容

### Requirement: 推送已持久化的执行事件

系统必须（SHALL）为每个运行任务提供有序的服务器发送事件流，其中包括步骤转换、等待状态、重试调度、失败、取消和完成事件。

#### Scenario: 客户端重新连接事件流

- **WHEN** 客户端携带有效的 `Last-Event-ID` 重新连接
- **THEN** 系统先按顺序补发已持久化的后续事件，再推送新事件

#### Scenario: 客户端打开已完成任务的事件流

- **WHEN** 客户端订阅一个已进入终态的运行任务
- **THEN** 系统返回请求范围内的历史事件和终态事件，且不改变运行任务状态

### Requirement: 安全地重试和取消运行任务

系统必须（SHALL）允许已认证的运营人员取消未终止的运行任务，并且只允许重试错误分类明确标记为可重试的失败步骤。

#### Scenario: 运营人员取消执行中的任务

- **WHEN** 运营人员请求取消一个未终止的运行任务
- **THEN** 系统记录取消请求，阻止新的下游工作，让当前处理器到达安全检查点，并最终将任务置为 `CANCELLED`

#### Scenario: 运营人员重试可重试步骤

- **WHEN** 运营人员重试因可重试瞬时错误而失败的步骤
- **THEN** 系统从最后一个安全检查点创建新的尝试，并保留之前的尝试记录用于审计

#### Scenario: 运营人员重试需要人工处理的错误

- **WHEN** 运营人员在未解决无效授权、验证挑战或未知发布结果的情况下重试步骤
- **THEN** 系统拒绝重试，并说明所需的人工操作
